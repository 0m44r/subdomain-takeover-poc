Mushroom poc @ intigriti

This page is a benign security-research proof of concept. It is not affiliated with, endorsed by, or operated by the owner of this hostname, and it contains no tracking, no data collection, no credential prompt and no active content.

The DNS record for this hostname was left pointing at GitHub Pages after the content it referenced was removed, and the parent domain carried no GitHub organisation domain-verification record. That combination allowed this hostname to be bound to an unrelated GitHub repository, which is what you are seeing now.

This was done solely to demonstrate the issue for a coordinated disclosure report, and is reported through Intigriti. Researcher handle: Mushroom.

The owner can reclaim this hostname immediately by removing or repointing the CNAME record, or by adding the GitHub organisation domain-verification TXT record. Please contact the reporter through the Intigriti submission to have this page taken down.
